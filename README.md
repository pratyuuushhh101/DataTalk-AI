#DataTalk AI

*Ambient Intelligence for Kirana Stores*
Overview
**DataTalk AI** is a voice-first, AI-powered system designed to bring real-time business intelligence to small retail stores (kirana shops).

Instead of requiring manual data entry or technical tools, the system **observes, understands, and assists** shopkeepers using:

* 🎤 Voice input
* 📷 Camera input
* 🤖 AI-driven insights

---

## 🎯 Problem

Small shop owners:

* Don’t track sales digitally
* Rely on memory and manual processes
* Lack visibility into profits, trends, and inventory

👉 Result:
Decisions are based on guesswork, not data.

---

## 💡 Solution

DataTalk AI introduces an **ambient intelligence layer** that:

* Captures shop activity via **voice + camera**
* Converts real-world interactions into structured data
* Generates **bills, insights, and suggestions in real-time**

👉 No typing. No training. No friction.

## 🏗️ Tech Stack

### Frontend

* React.js (TypeScript)
* Browser Media APIs (mic + camera)

### Backend

* Node.js + Express
* REST APIs

### AI & Cloud

* Azure OpenAI (NLP, insights)
* Azure Speech-to-Text
* Computer Vision

### Storage

* Azure Cosmos DB
* Azure Blob Storage

### Integrations

* WhatsApp Deep Links
* IP Webcam (mobile camera feed)

---

## 🔄 Data Flow

```
User (Voice + Camera)
        ↓
Frontend Capture (React)
        ↓
Backend (Node.js)
        ↓
Speech → NLP → Vision
        ↓
Multimodal Fusion
        ↓
Business Logic (Billing + Suggestions)
        ↓
Database Storage
        ↓
Frontend Output (UI)
```


## 🎯 Vision

> Turn every kirana store into a **self-aware, data-driven business**
> without changing how shopkeepers work.
